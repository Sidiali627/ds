# الهدف

هذا الملف هو المرجع الرسمي لجميع مكونات واجهة المستخدم (UI Components).

أي مكون جديد يجب أن يكون متوافقًا مع هذا الملف.

لا يسمح بإنشاء مكونات عشوائية أو مختلفة عن بقية المنصة.

# Responsive Rules

كل Component يجب أن يعمل على:

• الهاتف

• التابلت

• اللابتوب

• الشاشات الكبيرة

---

# Accessibility

كل Component يجب أن:

• يدعم لوحة المفاتيح

• يدعم Screen Readers

• يحتوي على ARIA Labels

• يدعم Focus States

---

# قواعد التطوير

أي Component جديد يجب أن:

• يكون قابلًا لإعادة الاستخدام.

• يكون متوافقًا مع DESIGN_SYSTEM.md.

• يدعم RTL.

• يدعم الوضع الليلي.

• يحافظ على الهوية البصرية.

• لا يكرر مكونًا موجودًا.

---

# المعيار النهائي
