# قاعدة البيانات الرسمية
## مشروع استوديو صحة الشباب

---

# الهدف

قاعدة البيانات هي القلب الحقيقي للمنصة.

جميع البيانات تحفظ داخل Supabase PostgreSQL.

لا يسمح باستخدام LocalStorage إلا لحفظ إعدادات الواجهة المؤقتة مثل اللغة أو الوضع الليلي.

جميع بيانات المستخدمين والمحتوى والاستبيانات والاستشارات تحفظ داخل قاعدة البيانات.

---

# المبادئ

• جميع البيانات مترابطة.

• لا توجد بيانات مكررة.

• جميع العمليات تعتمد على العلاقات.

• جميع الجداول محمية بواسطة Row Level Security.

# قواعد قاعدة البيانات

أي ميزة جديدة يجب أن:

• تمتلك جدولًا واضحًا.

• تكون مرتبطة بالمستخدم.

• تكون محمية بـ RLS.

• تسجل العمليات داخل Audit Logs.

• لا تكرر البيانات.

• تدعم التوسع مستقبلاً.

قاعدة البيانات يجب أن تكون قابلة للنمو دون إعادة تصميمها.
