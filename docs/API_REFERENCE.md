# أخطاء النظام

أي خطأ يجب أن:

• يسجل داخل النظام.

• يعرض رسالة واضحة للمستخدم.

• لا يكشف أي معلومات حساسة.

---

# قواعد استخدام API

أي خدمة جديدة يجب أن:

• تعتمد على Supabase.

• تحترم RLS.

• تتحقق من الصلاحيات.

• لا تكشف البيانات.

• تعيد استجابة واضحة.

• تستخدم معالجة أخطاء مناسبة.
