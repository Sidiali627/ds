# الهدف

هذا الملف يحدد جميع العناصر التي يجب أن تكون قابلة للإدارة من لوحة التحكم.

أي عنصر يظهر للمستخدم يجب أن يكون قابلاً للإضافة أو التعديل أو الحذف من لوحة الإدارة.

لا يسمح بوجود محتوى ثابت داخل الكود.

# أهم قاعدة

أي نص، صورة، زر، أيقونة، لون، رابط، صفحة، قسم أو عنصر يظهر داخل الموقع يجب أن يكون قابلاً للإدارة من لوحة التحكم.

إذا تمت إضافة ميزة جديدة مستقبلاً، فيجب إنشاء صفحة إدارة خاصة بها داخل لوحة الإدارة وربطها بقاعدة البيانات.
